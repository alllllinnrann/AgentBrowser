# Agent Browser

在基础浏览器功能上增加以 Agent 为核心的 Windows 网页工作工具。

## 功能

- 多标签、地址搜索、前进后退刷新、页面缩放、登录持久化、恢复标签网址与缩放。
- Agent 侧边栏、新建与切换对话、共享会话的独立聊天窗口、流式响应、Markdown 回复、停止、重试和操作记录。
- 绑定标签的网页工具：正文与 iframe 读取、长正文分段读取、全文查找、元素点击、输入、按键、滚动、等待、打开网页、历史检索。
- 网页截图与截图坐标点击：Agent 可查看当前网页画面，并点击帖子、链接、按钮或画布区域，不移动系统鼠标。截图理解需要支持图片输入的模型；画面变化时重新截图，点击仍会改变网页内容或输入焦点。
- 右键鼠标手势：左划后退、右划前进、上后下刷新、下后右关闭标签。
- token 预算估算、自动摘要、摘要失败本地截取、单条超长输入限额、原始历史保留。
- 每日本地定时任务、立即运行、启停和执行状态。
- SQLite 本地保存、对话删除、JSON 全量记录备份、网页/模型独立代理。

## 配置

使用 Windows x64 安装包无需配置 Node.js。在 Agent 设置中填写模型 API 地址、模型名称和密钥；本地无密钥接口可留空密钥。

从源码运行需要 Node.js 24+。运行：

```powershell
npm ci
npx install-electron
npm start
npm run check
npm run package -- --config.directories.output=outputs/releases/v0.3.3
```
