# Agent Browser

在基础浏览器功能上增加以 Agent 为核心的 Windows 网页工作工具。

当前版本为v0.3.0

## 功能

- 多标签、地址搜索、前进后退刷新、页面缩放、登录持久化、恢复标签网址与缩放。
- Agent侧边栏、新建与切换对话、共享会话的独立聊天窗口、流式响应、停止、重试和操作记录。
- 绑定标签的网页工具：观察、查找、点击、输入、按键、滚动、等待、打开网页、历史检索。
- token 预算估算、自动摘要、摘要失败本地截取、单条超长输入限额、原始历史保留。
- 每日本地定时任务、立即运行、启停和执行状态。
- SQLite 本地保存、对话删除、JSON 全量记录备份、网页/模型独立代理。

## 配置

Node.js 24+。运行：

```powershell
npm start
npm run check
npm test
npm run smoke
npm run package
```
